# mediDOK Cloud - Test Landing Page

Diese Test-Landing-Page präsentiert das fiktive Produkt "mediDOK Cloud" und dient als Vorlage für eine professionelle medizinische Cloud-Lösung.

## Projektstruktur

- `index.html` - Hauptseite mit der gesamten Landing-Page-Struktur
- `styles.css` - Stylesheet für das Design und Layout
- `script.js` - JavaScript für Interaktivität und Funktionalität
- `README.md` - Diese Datei

## Features

- Responsive Design (mobile-freundlich)
- Modernes und professionelles Layout
- Interaktive Elemente:
  - Smooth Scrolling Navigation
  - Kontaktformular mit Validierung
  - Animierte Feature-Karten
  - Sticky Header

## Lokale Nutzung

Um die Landing-Page lokal zu testen:

1. Laden Sie alle Dateien in ein Verzeichnis
2. Öffnen Sie die `index.html` Datei in einem Webbrowser

## Anpassung

Sie können die Landing-Page leicht an Ihre Bedürfnisse anpassen:

- Ändern Sie die Texte in der `index.html`
- Passen Sie die Farben und Stile in der `styles.css` an
- Ergänzen Sie zusätzliche Funktionalitäten in `script.js`
